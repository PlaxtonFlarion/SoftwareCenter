# 正文目录
第一次使用先读[项目总览](../README.md#quick-start)；已经有明确目标时，按下方分组选择对应指南。

## 按任务方向阅读
### 入门与入口
选择终端、桌面或订阅入口，了解启动方式、会话管理和连接准备。

- [命令行使用参考](cli-usage.md)
  查询终端命令、参数与组合示例，涵盖任务执行、会话恢复、模型配置和 MCP 管理。
- [原生桌面 Sidecar](desktop-sidecar.md)
  通过 computer 观察和操作本机窗口；区分日常启用、Windows/macOS 构建与原生桌面验收。
- [交互模式](interactive-mode.md)
  掌握对话输入、工具审批、模型切换与会话恢复，了解每个快捷键和 slash 命令的作用。
- [订阅模式](agent-mode.md)
  使用 agent listen 持续接收远端任务，管理连接、会话与中断后的恢复。

### 编排与协议
配置工具与自动化流程，组织请求参数，并核对结果和状态。

- [上下文用量客户端契约](context-usage-protocol.md)
  上下文用量事件、压缩与恢复，以及终端余量显示的权威数据口径。
- [会话删除客户端契约](session-deletion-protocol.md)
  正式删除请求、完成回执、未知结果恢复与本地资源所有权边界。
- [Hooks 配置](hooks.md)
  在会话和任务的生命周期中接入自动化脚本，配置发现规则、信任与执行权限。
- [MCP Server](mcp-server.md)
  将代理能力接入支持 MCP 的应用，配置 stdio 服务并了解工具调用和关闭流程。
- [接口实战](playbook.api.md)
  从发送请求到提取数据、验证断言，组织可重复执行的接口任务。
- [模板能力](playbook.template.md)
  使用变量与表达式构建请求模板，准备签名材料并明确模板的处理边界。

### 执行与取证
完成代码、设备和媒体任务，保存可复核的文件、画面或日志。

- [设备域实战](playbook.device.md)
  连接设备、选择操作能力，并将单设备动作扩展为可控的多设备任务。
- [原生 coding 链路](playbook.nativecoding.md)
  检查工作区、运行命令、应用补丁，再通过验证确认代码修改的结果。
- [Monkey 扰动](playbook.monkey.md)
  配置随机扰动任务，理解执行参数、停止条件与返回结果。
- [多媒体链路](playbook.media.md)
  准备本地媒体工具与输入文件，完成抽帧、转码和音轨处理；按需接入 Helix 录屏与试听。

### 性能与安全
设计性能与稳定性检查，按服务协议处理签名、令牌和密文。

- [安全工具](playbook.security.md)
  查阅摘要、JWT、RSA 与 AES 工具的用法，区分数据准备、签名和加解密步骤。
- [云端压测与任务收束](playbook.load.md)
  组织云端分布式压测，跟踪异步任务，并在结束时核对执行结果。
- [性能实战](playbook.performance.md)
  结合画面证据、资源趋势与稳定性扰动，定位性能问题并验证优化结果。

### 结构与维护
理解产品组成，维护文档发布，并执行平台与服务验收。

- [产品背景与能力生态](architecture.md)
  了解产品的使用场景、可选能力与生态组件；架构职责以正式架构文档为准。
- [维护者指南](maintainer-guide.md)
  维护文档事实源、站点导航与发布流程，确保源码和线上内容保持一致。
- [外接 MCP OAuth 验收](mcp-oauth-acceptance.md)
  源码或安装入口、系统凭据库和真实服务的重复验收步骤及脱敏记录模板。

## 阅读建议
- 先解决当前任务，再回来看结构文档；索引页负责导航，不负责替代正文
- 如果你正在补协议、模板、设备或媒体链路，优先读对应专题，再回到 README 看入口说明
- 如果你在维护官网壳或同步链路，优先看 `维护者指南` 和 `背景与架构`
